# BitPlayer/比特神播

> 一起看、一起聊、一起找——基于 IPv6 的个人 PC 端 MP4 播放器

BitPlayer 是一款面向家用个人 PC 的轻量级桌面播放器，让分散各地的用户能够**同步观看同一系列 MP4 视频**、**实时发送弹幕互动**，同时提供**资源搜索**与**MP4 下载**能力。网络层优先利用 IPv6 的地址优势进行端对端直连，直连不可达时自动降级到中继服务，兼顾低延迟与连接成功率。

### 系统要求

### 网络环境要求

- **支持 IPv6**：需要有可用的全球单播 IPv6 地址（非仅链路本地 `fe80::/10`），并允许出站 IPv6 连接
- 推荐带宽 10 Mbps 以上；同步播放与弹幕对延迟敏感，建议延迟低于 100 ms
- **连接策略**：客户端之间优先尝试直连；直连不可达时，自动降级经由中继服务器转发，保证房间内成员不掉线
- 企业网络、校园网或代理环境下，请确认防火墙未阻断 IPv6 出站流量

**快速检测 IPv6 连通性**（PowerShell）：

```powershell
Test-NetConnection -ComputerName ipv6.google.com -Port 443
# 或
ping -6 2001:4860:4860::8888
```

## ❓ 常见问题

**Q：提示「IPv6 不可用」怎么办？**
A：依次检查：① 路由器是否开启 IPv6 并下发前缀；② 网卡是否获取到全球单播地址；③ 系统防火墙是否放行客户端出站；④ 若运营商未提供 IPv6，可考虑使用隧道服务，但延迟会受到影响。

**Q：能加入房间但一直不同步？**
A：多为直连失败后的中继链路延迟过高。可在设置中确认连接模式，或让房主重新创建房间以触发新一轮直连探测。

**Q：下载速度很慢或中断？**
A：尝试降低并发数、更换资源来源；断点续传会在恢复后从已下载位置继续。

**Q：是否支持 MP4 以外的格式？**
A：当前版本仅支持 MP4。其他格式支持计划见下方路线图。
